# stellar-link-hub

Scaffold gerado pelo **ZenBrief** (Next.js + TypeScript + Tailwind).

## Começar

```bash
npm install
npm run dev   # http://localhost:3000
```

## Fluxo com opencode

- `BRIEFING.md` — briefing arquitetural do projeto.
- `AGENTS.md` — regras dos agentes.
- `/briefing` e `/scaffold` — comandos em `.opencode/commands/`.
